About CropCare AI

Harnessing the power of deep learning and computer vision to protect crops, empower farmers, and build a more food-secure world — one leaf scan at a time.

🌱 What is Crop Disease Detection?

Crop disease detection is the process of identifying diseases, infections, and nutrient deficiencies in plants by analyzing visual symptoms on leaves and other plant parts. Traditionally, this required expert agronomists to physically inspect fields — a time-consuming and costly process.

CropCare AI automates this by using a convolutional neural network trained on tens of thousands of annotated plant images. A farmer simply photographs a plant leaf, uploads it to the app, and within seconds receives a diagnosis — along with treatment recommendations.

This approach makes expert-level plant pathology accessible to anyone with a smartphone, regardless of location or agricultural knowledge, dramatically lowering the barrier to early intervention.

🧠 How Deep Learning Works

Three powerful ideas combine to make CropCare AI possible.

🔲

1. Convolutional Neural Network (CNN)

CNNs learn to detect edges, textures, and patterns in images through stacked convolutional layers. Each layer learns increasingly abstract visual features — from simple gradients to complex shapes like spots and lesions.

🔄

2. Transfer Learning

Instead of training from scratch, we borrow a model already trained on 1.4 million images (ImageNet). This gives us a powerful visual feature extractor for free, then we fine-tune it on plant disease data.

🤖

3. MobileNetV2

MobileNetV2 is an efficient CNN architecture designed to run on mobile and edge devices. Using inverted residuals and depthwise separable convolutions, it achieves high accuracy with a fraction of the computational cost.

📷 Raw Image → 🔧 Pre-process → 🤖 CNN Feature Extract → 🎯 Classify → 📋 Result

🤖 Why MobileNetV2?

We evaluated several architectures. MobileNetV2 stood out for all the right reasons.

⚡

Lightweight

Only 3.4M parameters and ~300MB footprint, making it ideal for deployment on resource-constrained servers and mobile devices.

📚

Pre-trained on ImageNet

Weights learned from 1.4M images give us exceptional out-of-the-box feature extraction requiring minimal fine-tuning data.

🏆

88% ImageNet Accuracy

Achieves top-1 accuracy of 71.8% on ImageNet, outperforming many heavier models while using far fewer operations (FLOPs).

⏱️

Real-Time Capable

Inference in under 2 seconds on CPU — no expensive GPU required, enabling truly accessible deployment anywhere.

📝 Training Configuration

Optimizer: Adam
Learning Rate: 1e-4
Loss: Categorical Cross-Entropy
Epochs: 20 (early stopping)
Batch Size: 32
Image Size: 224 × 224
Train Split: 80%
Val Split: 20%

🚀 Training Instructions (Windows)

Follow these steps to set up the environment and train the model on your machine.

PowerShell / Command Prompt
# Step 1: Create and activate virtual environment
PS> python -m venv venv
PS> venv\Scripts\activate

# Step 2: Install dependencies
(venv) PS> pip install -r requirements.txt

# Step 3: Download PlantVillage dataset → place in:
dataset/PlantVillage/

# Step 4: Train the model
(venv) PS> python model/train_model.py

# Step 5: Run the Flask application
(venv) PS> python app.py

# Step 6: Open in your browser
🌐 http://localhost:5000
⚠️ Tip: Training requires at least 8GB RAM. Using a GPU (CUDA) will significantly speed up training. CPU training may take several hours. The trained model is saved to model/crop_disease_model.h5.
